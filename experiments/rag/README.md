# Как заполнять RAG

База знаний хранится в `knowledge_base.jsonl`, по одной записи на строку:

```json
{"id":"unique_id","source":"chapter_or_topic","text":"фрагмент теории, пример решения или правило"}
```

## Рекомендованный пайплайн наполнения

1. **Источники**:
   - школьные учебники и методички с открытой лицензией;
   - свои конспекты и авторские объяснения;
   - банк задач с решениями (только если есть права на использование).

2. **Нарезка на чанки**:
   - 500-1000 символов;
   - один концепт на чанк;
   - сохранять источник (`source`) и тему.

3. **Очистка**:
   - убрать дубликаты;
   - убрать фрагменты без смысловой нагрузки;
   - проверить кодировку UTF-8.

4. **Валидация**:
   - вручную проверить 50-100 случайных чанков;
   - убедиться, что чанк самодостаточен и понятен без соседнего текста.

5. **Версионирование**:
   - хранить снимки как `knowledge_base_v1.jsonl`, `knowledge_base_v2.jsonl`;
   - фиксировать изменения в changelog экспериментов.
