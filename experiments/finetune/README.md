# Вариант дообучения open-source модели

Рекомендуемый базовый вариант для диплома:

- **Модель**: `Qwen2.5-7B-Instruct`
- **Подход**: LoRA / QLoRA (PEFT), чтобы обучать на одной GPU без полного fine-tune.

## Как собрать датасет для дообучения

Используй формат "задача -> педагогичное решение -> финальный ответ".

Одна запись в JSONL:

```json
{
  "task_id": "math_123",
  "subject": "algebra",
  "difficulty": "basic",
  "messages": [
    {"role":"system","content":"Ты обучающий ассистент, объясняй ход решения пошагово."},
    {"role":"user","content":"Реши уравнение 3x-9=0"},
    {"role":"assistant","content":"Подсказка: сначала перенеси -9... \nШаги: ... \nОтвет: 3"}
  ]
}
```

## Где взять данные (этично и легально)

1. Собственные авторские решения и задачи.
2. Open-source наборы с подходящей лицензией (MathInstruct, OpenMathInstruct, NuminaMath и т.д.) с фильтрацией под школьный уровень.
3. Полуавтоматическая генерация:
   - взять задачу;
   - сгенерировать решение teacher-моделью;
   - вручную/скриптом отфильтровать плохие объяснения.

## Минимальные требования к качеству

- В каждом примере обязателен финал в формате `Ответ: ...`.
- Нельзя оставлять "скачки" в логике.
- Удалять неоднозначные или ошибочные решения.
- Балансировать предметы и уровни сложности.

## Рекомендуемый размер

- MVP: 5k-20k хороших примеров.
- Уверенное сравнение в дипломе: 30k+ примеров с валидацией.
